**OSQuery** is an open-source operating system instrumentation and analytics framework that exposes the operating system as a relational database. It enables security analysts and system administrators to query system information using SQL statements, making it easier to monitor, investigate, and analyze endpoints across Windows, Linux, and macOS.


### **Benefits of OSQuery**

- Provides a **SQL-based interface** for querying operating system data.
- Simplifies **incident response** by allowing investigators to quickly collect endpoint information.
- Supports **threat hunting** by identifying suspicious processes, services, network connections, and system changes.
- Enhances **digital forensics** by enabling detailed system investigations.
- Improves **security monitoring** through scheduled and real-time queries.
- Assists with **compliance and auditing** by collecting and verifying system configuration data.
- Cross-platform support for **Windows, Linux, and macOS**.
- Integrates with **SIEM**, **EDR**, and **XDR** solutions to enhance security visibility and detection capabilities.
